IMPERIAL CREDENTIALS

Your credential is stored in this browser only and is sent directly to Anthropic. This site has no backend and cannot see it.

Holonet Direct. Paste a credential above and the page calls Anthropic straight from your browser. There is no server in between and nothing is sent anywhere else — whoever hosts this page never sees your key. If Anthropic does not permit direct browser access for your credential you will see a CORS error; that is expected, not a bug in this app. An API key generally works where an OAuth token may not. A word of advice: use a dedicated key with a spend limit. An Anthropic key is account-wide and carries your billing.

VOCODER

Which voice speaks, and how. Voices come from your operating system, so this list differs from machine to machine — and none of them is the real thing.

Tune the voice first, then the pitch. A floored pitch on a bright voice sounds damaged rather than deep — if the best voice your system offers is a cheerful one, try 0.4–0.5 instead of 0.1. Nothing here is stored anywhere but this browser, and changes apply to the next thing spoken.
